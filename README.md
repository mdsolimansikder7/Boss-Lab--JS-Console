# 🧪 Boss Lab Console

A browser-based code playground where you can write code in a real code editor, run it, and see the output instantly. Supports **JavaScript, Python, C and C++**. Built with React, TypeScript and Vite.

🔗 **Live Demo:** [boss-lab-console.vercel.app](https://boss-lab-console.vercel.app/)

---

## ✨ Features

- 📝 **Code editor** powered by Monaco (the same editor used in VS Code)
- 🌐 **Multi-language support:** JavaScript, Python, C and C++
- ▶️ **Run code** and see the output right in the browser
- 🎨 **Clean, responsive UI** styled with Tailwind CSS
- 🎞️ **Smooth animations** with Motion
- ⚡ **Fast development and build** with Vite

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/mdsolimansikder7/Boss-Lab-Console.git
   cd Boss-Lab-Console
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm run dev
   ```

   Open [http://localhost:3000](http://localhost:3000) in your browser.
